## 技术栈：

前端 React+后端 Fastapi （Python）
数据库：postgresql


# 核心功能 
1、测试：测试用户的知识点，生成学习规划（AI - API）

2、 Roadmap（首页）- 选择 1 个知识点，然后生成对应知识点的练习题（quiz & solution）

完成练习题（知识点掌握后），可以进行刷题。

对应知识点内容的生成：

- 写死：我们自己学习中，遇到的好的资源，我们做一个集合。
- AI
3、如果用户写了一个代码，可以 AI 生成你目前代码中错误的部分，根据你的思路写出正确的代码。

如果用户不懂，可以用 AI 调 API 来进行数据结构策略和解答策略的提示。

最后用户可以添加笔记。

Hint：

第一层：算法策略（文字版）——看用户能否生成正常的代码

第二层：代码解答

第三层：推荐 youtube 的视频链接
