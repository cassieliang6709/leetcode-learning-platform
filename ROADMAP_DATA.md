## 🎯 完整知识点列表

### 📊 Arrays & More (6 topics)

#### 1. Arrays & Hashing ⭐ Easy
**描述：** Master array operations and hash table techniques for O(1) lookups. Essential for solving problems efficiently.

**核心技能：**
- Array traversal and manipulation
- Hash map for frequency counting
- Two sum and related patterns
- Set operations

**经典题目：**
- Two Sum
- Contains Duplicate
- Group Anagrams
- Top K Frequent Elements

---

#### 2. Two Pointers ⭐ Easy
**描述：** Learn to use two pointers technique for solving array and string problems in linear time without extra space.

**核心技能：**
- Left and right pointers
- Fast and slow pointers
- Partition techniques
- In-place operations

**经典题目：**
- Valid Palindrome
- Two Sum II
- Container With Most Water
- Remove Duplicates

---

#### 3. Sliding Window ⭐⭐ Medium
**描述：** Master the sliding window pattern for subarray and substring problems. Critical for optimization problems.

**核心技能：**
- Fixed-size window
- Variable-size window
- Window with constraints
- Maximum/minimum in window

**经典题目：**
- Longest Substring Without Repeating
- Minimum Window Substring
- Sliding Window Maximum
- Longest Repeating Character

---

#### 4. Binary Search ⭐⭐ Medium
**描述：** Master binary search for sorted arrays and search space problems. Achieve O(log n) time complexity.

**核心技能：**
- Basic binary search
- Search in rotated array
- Find minimum/maximum
- Search space reduction

**经典题目：**
- Binary Search
- Search in Rotated Sorted Array
- Find Minimum in Rotated Array
- Koko Eating Bananas

---

#### 5. Intervals ⭐⭐ Medium
**描述：** Master interval problems: merge intervals, meeting rooms, and insert intervals.

**核心技能：**
- Interval sorting
- Merge overlapping intervals
- Interval insertion
- Meeting room scheduling

**经典题目：**
- Merge Intervals
- Insert Interval
- Non-overlapping Intervals
- Meeting Rooms II

---

#### 6. Bit Manipulation ⭐ Easy
**描述：** Master bitwise operations for efficient solutions to counting and XOR problems.

**核心技能：**
- XOR properties
- Bit masks
- Count set bits
- Power of two check

**经典题目：**
- Single Number
- Number of 1 Bits
- Counting Bits
- Reverse Bits
