## Hint 系统结构

每道题都包含 3 级 Hints：

### Hint 1: 算法策略（英文）
提供解题思路和算法模式识别，帮助理解问题本质。

**示例（Two Sum）：**
```
For Two Sum: Analyze the problem and identify the key data structure 
and algorithm pattern. Consider the constraints and think about 
optimal time/space complexity.
```

### Hint 2: 核心代码模板
提供代码框架和时间空间复杂度提示。

**示例（Two Sum）：**
```python
# Two Sum - easy
# Category: array
# Implement your solution here
# Time: O(?), Space: O(?)
```

### Hint 3: YouTube 视频教程
每题都附带 NeetCode 或其他优质教程视频链接。

**示例：**
```
Watch NeetCode's explanation for detailed walkthrough
🎥 https://www.youtube.com/watch?v=KLlXCFG5TnA
```

## 数据库验证

### 验证命令

```bash
# 查看题目总数
psql -d leetcode_learning -c "SELECT COUNT(*) FROM quiz_questions WHERE knowledge_point_id >= 10;"

# 查看知识点统计
psql -d leetcode_learning -c "
SELECT kp.name, COUNT(q.id) as count 
FROM knowledge_points kp 
LEFT JOIN quiz_questions q ON kp.id = q.knowledge_point_id 
WHERE kp.id >= 10 
GROUP BY kp.name 
ORDER BY count DESC;
"

# 验证 hints 完整性
psql -d leetcode_learning -c "
SELECT 
  COUNT(*) as total,
  COUNT(CASE WHEN jsonb_array_length(hints::jsonb) = 3 THEN 1 END) as with_3_hints,
  COUNT(CASE WHEN video_link IS NOT NULL THEN 1 END) as with_video
FROM quiz_questions 
WHERE knowledge_point_id >= 10;
"
```
