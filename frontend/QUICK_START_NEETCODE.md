# 🚀 快速开始 - NeetCode 风格界面

## 立即体验全新设计！

### 步骤 1：启动前端

```bash
cd frontend
npm install  # 如果是第一次运行
npm run dev
```

### 步骤 2：访问浏览器

打开浏览器访问：`http://localhost:5173`

### 步骤 3：体验新功能

#### 🌓 切换主题
- 点击导航栏右上角的 **☀️/🌙** 按钮
- 在深色和浅色主题间切换
- 主题选择会自动保存

#### 🗺️ 浏览 Roadmap（重点！）
1. 点击导航栏的 **"Roadmap"**
2. 查看左侧的分类导航
3. 点击不同分类筛选知识点
4. 查看右上角的进度圆环
5. 点击任意卡片开始学习

## 🐛 故障排除

### 样式没有生效？
```bash
# 清除缓存
rm -rf node_modules/.vite
npm run dev
```

### 主题切换不工作？
```bash
# 清除浏览器 localStorage
localStorage.clear()
# 刷新页面
```

### 响应式问题？
- 检查浏览器窗口大小
- 使用开发者工具的响应式模式
- 测试不同的断点
